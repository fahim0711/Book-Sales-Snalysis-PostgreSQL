**Book Sales Analysis Using PostgreSQL**



A SQL project focused on analyzing book sales, customer purchasing behavior, and inventory management using PostgreSQL.



**#Technology Stack**

* Database: PostgreSQL
* Language: SQL
* Dataset: 3 CSV files



**#Database Tables**

1. book\_data – Book details, prices, genres, and stock.
2. customer\_data – Customer information and locations.
3. orders\_data – Order dates, quantities, and sales amounts.



**#Project Analysis**



1. **Basic Analysis (11 Questions)**



Book filtering by genre and publication year

Sales calculations using aggregate functions

Order analysis using date range filtering

Data summarization using GROUP BY

Book and order data analysis using LEFT JOIN



**2. Advanced Analysis (11 Questions)**



* Sales Analysis: Customer spending, book sales, and revenue calculations
* Customer Analysis: Purchase behavior and spending comparisons
* Inventory Analysis: Remaining stock calculations using LEFT JOIN, SUM(), and COALESCE()
* Ranking Analysis: Ranking records using ROW\_NUMBER() and DENSE\_RANK()
* Time-Based Analysis: Monthly revenue and book sales trends using EXTRACT()
* Advanced Querying: Multi-table joins, window functions, and HAVING



**#Key Skills**

PostgreSQL, SQL Joins, Aggregate Functions, Window Functions, Sales Analysis, Customer Analysis, and Inventory Analysis.
